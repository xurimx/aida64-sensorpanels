Importing

  1. Import it in SensorPanel Manager.Right-click the panel, open SensorPanel Manager, click Import and pick the file. The import replaces the current layout.
  2. Extra readings depend on your hardware.Coolant, 12VHPWR, memory stick and GPU limit readings only appear if your parts report them. Memory temperatures also need File › Preferences › Stability › DIMM thermal sensor support turned on, followed by a restart of AIDA64. Untick any that show blank or 0, then export again.
  3. Fixed parts.The core grid is laid out for a 6 P + 8 E Intel CPU, the FPS readout needs RivaTuner Statistics Server, and readings use Segoe UI.
  4. If it still lands at the wrong size.Older AIDA64 builds handle Windows scaling inconsistently. You can switch scaling off for AIDA64 instead: right-click aida64.exe › Properties › Compatibility › Change high DPI settings, tick "Override high DPI scaling behavior", choose System and restart Windows. Then export with the scale at 100 % and the resolution at your scaled size, for example 1920 × 1080 for a 4K screen at 200 %. Text will be a little soft. AIDA64's newer betas also fixed several mixed-scaling bugs.
  5. Your settings stay in this browser.Come back later, change one thing and export again.
