AIDA64 Sensor Reference

Every reading AIDA64 can put on a SensorPanel, grouped the way its manual lists them. Your PC only reports the ones its hardware has. SensorPanel Manager's sensor dropdown shows exactly which ones those are.

Worth adding to Modern Split

Picked for your setup: an Intel 6P + 8E CPU, a graphics card, two drives, an AIO and gaming on a second screen. Readings already on the panel aren't repeated here.

    Panel building blocks

    These are the item types in SensorPanel Manager. A reading from the list below goes into one of them.

    ItemWhat it doesWhere Modern Split uses it
    LabelFixed text with font, colour and style.Not used. Labels are drawn into the background so they look the same on any PC.
    ImageA picture, optionally a link that opens a URL or program when double-clicked.The background.
    Simple sensor itemOne reading as text, with optional label and unit.Clocks, temperatures, MB used, read/write speeds, fan RPM.
    Sensor itemLabel, value, unit and an optional bar in one item.Not used. The bars are custom gauges instead, for the segmented look.
    GraphHistory of one reading as a line or area graph, with optional grid and auto-scaling.FPS, CPU and GPU load, network.
    GaugeBuilt-in dial skins, or a custom gauge that flips between 16 of your own images.Every ring and segmented bar, plus the big centred numbers.

    Every sensor

    Rows ending in a range, like SDSK1ACT–SDSK25ACT, repeat once per device. GPU2 to GPU12 repeat the GPU1 rows with their own number.

    Source: AIDA64's Complete Sensor value list. The voltage, current and power sections are condensed here. Rail groups you'd rarely put on a panel are shown as one row, marked "group".

    The manual writes core IDs with two digits (SCC-1-01). Panels saved by AIDA64 use SCC-1-1, which is the form Modern Split uses.
