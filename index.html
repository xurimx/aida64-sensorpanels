Put a panel on your screen

  1. Export a file from the builder, or download the Classic OLED file.
  2. In AIDA64, open File › Preferences › Hardware Monitoring › SensorPanel and tick Show SensorPanel.
  3. Right-click the panel, open SensorPanel Manager, choose Import and pick the file.
  4. Drag the panel onto the second screen.

If a reading shows 0 or is missing

Frame rate
AIDA64 reads FPS from RivaTuner Statistics Server, so RTSS has to be running.
Network
AIDA64 numbers virtual adapters too, so your network card may be NIC2 or higher. Set the number under Network in the builder.
Memory temperatures
Turn on DIMM thermal sensor support under Preferences › Stability, then restart AIDA64. Pick your populated slots in the builder.
Layout looks off with Windows scaling
Above 100 %, AIDA64 enlarges text and positions but not images. Set the same scale in the builder's Display section before exporting.
